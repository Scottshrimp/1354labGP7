MEGALOVANIA — 独立运行、简单模式

1. 在网站使用“打开”导入项目根目录下 src/deploy/main.py 到 https://python.microbit.org/，
   然后发送至 micro:bit V2。只需要这一个文件，不用把 MIDI 或 JSON 放进设备。
   src/deploy/main.py 是压缩刷入版；src/microbit_main.py 保留易读源代码。
2. 插入课程 GamePad，打开电源，调节外接扬声器音量旋钮。
3. 摇杆右推开始，倒计时后播放主旋律；方向键按箭头。
   摇杆左推暂停，右推恢复；暂停时下推退出；结果页左推返回。
   每次操作后让摇杆回到中心，再进行下一次操作。

不需要电脑播放、FFmpeg、串口主机或额外音频模块。刷入后可用电池运行。
P12 输出电子旋律，经已有功放驱动外接扬声器；P0/P1 保留给摇杆。
音乐是用户提供 MIDI 第 3 轨的单音主旋律，约 159 秒，无原唱和低音伴奏。

简单谱面：114 个单键，普通间隔约 1.043 秒，每 12 个提示后有约 5.2 秒空档。
同方向连续两次，之后按上、右、下、左循环；开头先听约 2 秒。
箭头提前 3 秒出现，Perfect ±220ms，Good ±400ms，误按其他方向不立即扣分。
漏按时短暂振动、亮灯；没有强制失败退出。实际难度需让目标使用者试玩调整。

编辑谱面（在项目根目录运行）：
  python src/chart_studio.py
打开 music/megalovania/chart.json；Import Audio 可以选择 source.mid 试听。
MIDI 试听使用同一主旋律转换器，临时 WAV 自动清理；试听依赖 pygame 和 Tkinter。

编辑并保存后，在项目根目录运行：
  python src/tools/build_song.py
再重新导入并刷入 src/deploy/main.py。这个命令保留手工修改的谱面。
  python src/tools/build_song.py --make-chart
会覆盖 JSON，重新生成默认简单谱面。构建只用 Python 标准库。
构建要求单键间隔至少 1000ms，方向为 UP/RIGHT/DOWN/LEFT，时间为整数毫秒。

验证：python -m unittest discover -s src/tests -v
已做桌面逻辑模拟；未连接实体设备验证。首次上板请检查音量、音乐/箭头同步、
双 OLED 刷新、暂停恢复、振动和方向键。不要把桌面模拟当作硬件验收。
