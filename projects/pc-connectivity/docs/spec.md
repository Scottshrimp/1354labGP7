# 双人电脑联机模式

- 独立的 micro:bit V2 游戏程序；切换单机与联机时重新刷入。初版通过 Chrome Python Editor 手动刷入；网页内刷写是后续工作。
- 本地网页由电脑服务提供，最多同时管理两台通过 USB 连接的 GamePad；允许单台调试。
- 初始曲目使用 standalone 的 MEGALOVANIA 和现有谱面。谱面由人和 AI 提前准备，不在游玩时自动生成；后续可扩展曲库。
- 选曲后完整传输并校验谱面，显示各设备连接、接收进度和准备状态。只有所有参与设备准备完成后才能开始。
- 电脑播放旋律音频；两台设备按协调的未来时刻启动。设备判定并上报分数和连击，网页显示实时状态。
- 结束按钮停止所有设备与音频，显示最终分数、最佳连击和排名；歌曲自然结束也显示结果。
- 通信中断时中止整局并停止音频，保留已收到的结果；重新连接后需重新准备。
- 计分沿用现有规则：Perfect 100 分，Good 50 分，Miss 0 分；连击独立展示，不作为分数倍率。
- 实机必须验证容量、同步误差、USB 稳定性、输入和显示；不承诺未经测量的同步精度。

- 两台 micro:bit V2 通过 Chrome Python Editor 刷入独立联机程序，各自握手成功，时钟周期均为 1,073,741,824 ms。
- 两台设备均完成 114 音符的完整传输与校验；网页显示两台准备完成，随后显示实时分数和连击。
- 用户确认两台箭头移动、电脑音乐和按方向键后的得分变化正常。
- 用户拔插一台设备时，主机结束本局，停止音乐并保留两台已收到的成绩。断开后重新连接和重新下载谱面可用。
- 尚未验证整首歌自然结束、长时间稳定性，未量化双机及音画误差；物理设备已断开。
