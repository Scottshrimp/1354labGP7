Rhythm Hit Tutorial

Getting started

Flash your micro:bit and play

Rhythm Hit Versus runs entirely in your browser. Flash one file onto each micro:bit, plug both boards into the same computer, and the page hosts the match.

Download main.py Open the console

What you need

  • 2 × micro:bit V2Each fitted to a GE1354 GamePad
  • 2 × USB data cablesCharge-only cables won’t show up
  • Desktop Chrome or EdgeWeb Serial isn’t available in Safari, Firefox or on phones

1 · Flash each board

  1. Download main.py

    Use the file from this site. It is built to match this page; older Rhythm Hit files won’t pair.

  2. Open the micro:bit Python Editor

    Centre the joystick and connect the first micro:bit over USB.

  3. Open main.py in the editor

    Use Open… and choose the downloaded file, replacing the current project. Don’t add any other files.

  4. Send to micro:bit

    Pick the board when Chrome asks. When flashing finishes, the OLED shows the standalone menu.

  5. Repeat for the second board, then close the editor tab

    The editor keeps the serial port open. Close it so this site can talk to the boards.

2 · Connect and play

  1. Plug both boards into this computer

    Keep the joysticks centred while they start up.

  2. Open the console and connect each player

    Click Connect player 1, choose a micro:bit, then do the same for player 2. Chrome remembers the boards, so later visits reconnect automatically.

  3. Pick a song and confirm

    Once both boards reach the multiplayer lobby, song selection opens. Turn your speakers on — the music plays from the computer.

  4. Ready up on the devices

    Each player pushes → on their own micro:bit. When both are ready the boards sync clocks and count down together.

  5. Hit the notes

    Push the joystick in the direction shown as each note reaches the line. Results appear on the page when the song ends; push ← on both devices to return to the lobby.

Troubleshooting

The Connect buttons are greyed out
Use desktop Chrome or Edge and open the site over https.
“No game handshake”
The board is running other code. Flash the main.py from this site again, and make sure the Python Editor tab is closed.
“Can’t open the serial port”
Another tab or program is using the board. Close the Python Editor, other Rhythm Hit tabs and any local Python host, then reconnect.
The board doesn’t appear in Chrome’s list
Try another USB cable or port; some cables only carry power.
A board unplugs mid-song
The other player keeps going and the unplugged player is marked as not finished. Plug it back in and it rejoins on its seat.
